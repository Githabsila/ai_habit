# Project ADAM — финальные правки 25.08.2026

## Уведомления
- 06:00 по локальному времени пользователя — ровно одно утреннее сообщение ADAM.
- 10:00 — отдельная контрольная точка по оставшимся привычкам.
- 12:00 — отдельные уведомления только по ещё невыполненным привычкам.
- Для 12:00 добавлены разные формулировки без повторения шаблона внутри одной рассылки.
- После 20:00 точечные напоминания задач плана дня не отправляются: вечерняя сверка собирает все открытые задачи в одно сообщение.
- 22:30 — учитывается главная задача и все второстепенные открытые задачи; исправлено склонение «1 задача, которая...» / «2+ задачи, которые...».

## UI
- Верхний левый огонь уменьшен примерно на 12%.
- Звёздочка у «Главная задача дня» слегка выровнена.
- Кнопки редактирования/удаления главной задачи возвращены в правый нижний угол карточки.
- Орбиты вокруг огня сделаны круглыми, а точки переходят между оборотами плавно.
- «Заморозок» → «Заморозки».
- Стоимость заморозки отображается как «❄️ ... 200 А».
- В профиле убран маленький огонь слева от «ТВОЯ УДАРНАЯ СЕРИЯ».
- Большой правый огонь в профиле немного опущен и уменьшен примерно на 15%.

## Производительность Mini App
- Первый `/api/bootstrap` теперь возвращает только критические данные Главной: профиль, привычки, план, ударный режим и настройки.
- Рейтинг, календарь, достижения и магазин вынесены в `/api/bootstrap-secondary` и загружаются после первого интерактивного кадра.
- Если пользователь сразу открывает второстепенную вкладку, данные догружаются немедленно.
- Статические JS/CSS/изображения кэшируются; HTML остаётся без кэша. Версии ассетов обновлены.
- Верхний огонь переведён с PNG (~250 KB) на WebP (~48 KB) без изменения визуального размера.
- Анимации ограничены transform/opacity-подходом и ставятся на паузу при скрытии Mini App.
- Добавлена поддержка `prefers-reduced-motion`.

## AI
- Повторный «Совет дня» всегда получает свежий контекст текущих привычек и плана.
- Основной чат оставлен на одном быстром LLM-вызове вместо тяжёлой мультиагентной цепочки.
- Если задан `GROQ_API_KEY`, пользовательский чат Mini App работает через Groq с `openai/gpt-oss-120b`; OpenAI остаётся резервным каналом.
- Повторы API сокращены до одного; таймауты уменьшены.
- Добавлено логирование фактической задержки AI-ответа.

## Проверка
- Python: `compileall` без синтаксических ошибок.
- JavaScript: `node --check` без синтаксических ошибок.
- Форматтеры уведомлений отдельно проверены для 1 и 2+ задач.
- Полный pytest в текущем окружении не запускается из-за отсутствующих зависимостей проекта (`openai`); это ограничение среды проверки, а не обнаруженная ошибка синтаксиса.
