# Project ADAM — изменения 25.08.2026

## Напоминания
- 06:00 — только одно персонализированное утреннее приветствие ADAM.
- В первые 15 минут после 06:00 отключены точечные пинги, чтобы утреннее сообщение не дублировалось.
- 10:00 — отдельная общая контрольная точка по невыполненным привычкам.
- 12:00 — отдельные сообщения только по оставшимся невыполненным привычкам.
- Формулировки 12:00 выбираются без повторения шаблона внутри одной рассылки.
- Индивидуальные 2-часовые напоминания по привычкам отключены, чтобы не создавать спам.
- Вечерняя сверка учитывает одновременно главную и все второстепенные открытые задачи.
- Для 1 задачи используется «которая ещё открыта», для 2+ — «которые ещё открыты».

## Ударный режим / UI
- Огонёк слева уменьшен примерно на 12%.
- Круги вокруг огонька теперь находятся в квадратном контейнере и не растягиваются в овалы.
- Оборот орбит оставлен полным 360° для бесшовного повторения.
- Маленький огонёк рядом с «Твоя ударная серия!» убран.
- Большой огонь справа в профиле уменьшен примерно на 15% и немного опущен.
- «Заморозок» → «Заморозки».
- Цена показана как «❄️ 200 А».
- Кнопки редактирования/удаления главной задачи явно прижаты вправо.

## Совет дня
- Убран дневной кэш совета.
- Каждый повторный тап получает свежий контекст текущих открытых/закрытых задач и привычек.

## Производительность
- Главная страница теперь сначала рендерит критический путь: профиль, привычки, план и ударный режим.
- Магазин, достижения, рейтинг и календарь дорисовываются через requestAnimationFrame/requestIdleCallback после первого кадра.
- Декоративные анимации ставятся на паузу, когда Mini App скрыт.
- На мобильных уменьшена стоимость декоративных blur-эффектов.
- Некритичные изображения профиля получили lazy loading/async decoding.
- В AI-чате обычный запрос переведён на один быстрый LLM-вызов; старый многоагентный каскад больше не запускается в обычном режиме.
- Таймаут OpenAI снижен с 120 до 15 секунд, повтор после временной ошибки — максимум один.
- Цель оптимизации: заметно снизить задержку ответа и нагрузку без отключения защитной проверки кризисных сообщений.
