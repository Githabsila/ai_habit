# Инструкция владельцу: что сделать до запуска оплаты

Составлено 06.11.2026. Идти сверху вниз: каждый шаг короткий, у каждого — как проверить, что получилось.
Где написано «скажи Claude» — открой сессию Claude Code с этим репозиторием и напиши фразу.

**Правило для всех ключей и паролей:** не присылать в чат и не класть в код. Только в Railway → Variables (или безопасная форма, которую откроет Claude).

---

## Шаг 0. Выложить последние изменения (5 минут)

Скажи Claude: «влей текущую ветку». Он создаст pull request, дождётся зелёных тестов, вольёт и проверит прод.
Что войдёт: автопродление и напоминания о конце срока, сообщения 3-го дня по серии, условия «30 дней» и возвраты через админа,
«Скрыть меня из рейтинга», согласие на обработку данных, автоудаление (выключено).

---

## Шаг 1. Railway → Variables (15 минут)

Railway → проект `aihabit` → сервис → вкладка **Variables** → **New Variable**. После сохранения Railway перезапустит бота сам.

| Переменная | Что поставить | Зачем |
|---|---|---|
| `SUBSCRIPTION_STREAK_DAYS_FOR_CHANNEL` | **удалить**, если там `2` | теперь по умолчанию 3 (решение 05.11) |
| `ADMIN_ID` | добавить свой Telegram ID через запятую к уже стоящим | чтобы видеть новые функции (задачи из чата, перенос на завтра) и админку |
| `BACKUP_ENCRYPTION_KEY` | ключ — попроси Claude «сгенерируй ключ шифрования копий» или запусти `python tools/make_backup_key.py` | копии базы и кода приходят зашифрованными. **Сохрани копию ключа в менеджере паролей: без ключа копии не открыть** |
| `SUPPORT_INSTAGRAM` | ник в Instagram без @ (например `adam_support`) | появится в `/paysupport`, `/terms` и в соглашении как способ вернуть оплату |
| `INACTIVE_PURGE_MONTHS` | `12` (или своё число месяцев), либо не трогать — тогда выключено | автоудаление аккаунтов, которые давно не заходили; за 30 дней бот предупреждает |

Свой Telegram ID: напиши боту `@userinfobot` — он ответит числом.

**Проверка:** через пару минут в Telegram у @aihabbit_bot `/paysupport` — в ответе есть Instagram; в админке видна карточка «Сообщения бота».

## Шаг 2. BotFather (10 минут)

Открой `@BotFather` → `/mybots` → выбери бота.

1. **Описание:** Edit Bot → Edit Description — что умеет ADAM (1–2 предложения).
2. **Команды:** Edit Bot → Edit Commands → вставь:
   ```
   start - Открыть ADAM
   paysupport - Вопросы по оплате и возврат
   terms - Условия подписки
   ```
3. **Политика конфиденциальности:** Bot Settings → Privacy Policy (если такого пункта нет — в настройках Mini App) → ссылка
   `https://aihabit-production.up.railway.app/privacy`.

**Проверка:** в чате с ботом при вводе `/` видны три команды.

## Шаг 3. Оплата картой — Tribute (Visa/Mastercard, СНГ) (1–2 часа, часть — ожидание проверки)

1. В Telegram открой `@tribute` → стать автором → пройди проверку личности (KYC). Ждать подтверждения может занять время.
2. Создай **цифровые товары** с ценами в долларах. Список товаров и цен — скажи Claude «список товаров для Tribute» (он выдаст из кода точные названия и суммы, их 8).
3. Настройки → **API Keys** → создай ключ → положи в Railway как `TRIBUTE_API_KEY`.
4. Настройки → **Webhooks** → адрес: `https://aihabit-production.up.railway.app/api/pay/webhook/tribute`.
5. Скажи Claude «ключ Tribute на месте, привяжи товары» — он привяжет товары к покупкам в админке (Оплата → Tribute).

**Проверка:** в админке → «Оплата» → товары Tribute помечены как привязанные.

---

## Шаг 4. Оплата картой «Мир» — Lava.top (РФ) (1–2 часа, часть — ожидание проверки)

1. Зарегистрируйся на **lava.top** как продавец, пройди проверку.
2. Создай продукт-**подписку** (ежемесячная): ADAM Pro, первый месяц $1.99 (если можно задать вводную цену) и дальше $5.99.
3. В кабинете создай **ключ API**. Положи в Railway как `LAVA_API_KEY` (или скажи Claude — он откроет безопасную форму).
4. Открой Claude доступ к документации: в настройках этой среды (стрелка у названия сессии → «Изменить облачную среду» → «Доступ к сети») добавь домены `lava.top` и `gate.lava.top`.
5. Скажи Claude «Lava готов» — он сделает интеграцию (оплата, автосписание, подтверждения) и покажет её у админов.

## Шаг 5. Тестовые покупки (30 минут, стоит ≈ $5)

С телефона, со своего аккаунта:

1. **Звёзды:** приложение → Профиль → «Подписка на Адама» → оплатить (153 ⭐). Проверь: пришло «Подписка активна до …», на экране подписки — дата.
2. **Автопродление:** сначала в Railway поставь `SUBSCRIPTION_AUTORENEW_ENABLED=true` (первая покупка у людей всё равно останется разовой по $1.99).
   Потом на экране подписки появится «Включить автопродление» → оплатить 461 ⭐. Проверь: на экране — «Списание повторяется каждые 30 дней»;
   срок продлился от конца текущего, а не от сегодня.
3. **Карта** (после шагов 3–4): то же через «Картой».
4. **Возврат:** админка → «Оплата» → платежи → скопируй номер операции → в чате с ботом `/refund НОМЕР`. Проверь: звёзды вернулись, подписка снята.
5. Скажи Claude время покупок — он сверит журналы и базу.

## Шаг 6. Посмотреть всё глазами (30 минут)

Админка (кнопка «Админ-панель» в меню бота):

- **«Сообщения бота»** — все сообщения, что бот шлёт сам: напоминания, таймер, конец подписки, сообщения 3-го дня. «Прислать мне» — придёт только тебе.
- **«Окна и анимации» → «📱 Смотреть на 5 телефонах сразу»** — любой экран сразу на Android, iPhone SE, iPhone 15, Pro Max и ПК.
- **«Триал»** — сообщения пробного периода и «машина времени» своего аккаунта.

Что не нравится в текстах — пиши Claude списком: «тут жёстче», «тут короче». Проход «жёсткий тренер» сделаем по этому списку.

## Шаг 7. Бета на живых людях (1–2 недели)

1. Пригласительная ссылка — админка → «Каналы и ссылки».
2. Кто помогает с багами — карточка человека → «Доступ» → +7 или +14 дней.
3. Новые функции — задачи из чата (`bot_quick_capture`) и перенос на завтра (`plan_carry_over`) — у админов уже включены, проверь их на себе.
   Тестировщикам включай в админке → флаги: сначала 20–30%, потом 100%.
4. Эксперимент напоминаний: карточка «Эксперимент: 5 или 7 напоминаний» → «Запустить 50/50». Через неделю — смотреть цифры.
5. Каждый день: админка → ошибки; что сломалось — пиши Claude.

## Шаг 8. Включение оплаты (5 минут, когда бета прошла и покупки проверены)

Railway → Variables:

| Переменная | Значение | Что включает |
|---|---|---|
| `SUBSCRIPTION_AUTORENEW_ENABLED` | `true` (если ещё не поставил на шаге 5.2) | автопродление звёздами |
| `EXTERNAL_PAYMENTS_ENABLED` | `true` | карты Tribute / Lava (после шагов 3–5). Риск по правилам Telegram ты принимаешь; выключается этим же флагом за минуту |
| `SUBSCRIPTION_GATE_ENABLED` | `true` | платный доступ после 3 дней триала |
| `SUBSCRIPTION_GATE_CUTOVER` | `all` | триал и оплата для всех, включая тех, кто пришёл раньше |

**Откат:** вернуть `false` — доступ снова открыт всем, деньги и данные не трогаются.

## Шаг 9. Закрытый канал (когда наполнишь — не мешает запуску)

1. Создай закрытый канал, добавь @aihabbit_bot администратором с правами «Приглашать» и «Удалять участников».
2. ID канала (вида `-100…`) — перешли любой пост из канала боту `@userinfobot` → положи в Railway как `CLOSED_CHANNEL_ID`.
3. Скажи Claude «канал подключён» — он включит упоминания канала в текстах (сейчас выключены по твоему решению).
