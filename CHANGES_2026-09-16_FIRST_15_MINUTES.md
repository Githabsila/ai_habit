# ADAM — первый опыт пользователя, 16.09.2026

## Что изменено

### 1. Заявка → быстрое одобрение
- После завершения анкеты администратору сразу приходит сообщение в Telegram.
- В сообщении есть краткие ответы из анкеты.
- Есть inline-кнопка `✅ Быстро одобрить` — отдельная админ-панель для простого одобрения не нужна.
- Есть кнопка `👀 Открыть заявки` для перехода к полному списку.
- Старую кнопку из уже обработанной заявки нельзя повторно применить.

### 2. Первые 15 минут Mini App
Длинный экранный тур заменён на небольшие контекстные подсказки:
- примерно через 2 секунды — привычки;
- далее — одна небольшая задача;
- при переходе в Календарь/Профиль подсказка появляется только в соответствующем разделе;
- AI/ADAM остаётся естественной следующей точкой, без показа пяти-шести окон подряд.

Прогресс onboarding хранится в БД, поэтому перезагрузка Mini App не сбрасывает его.

### 3. Первый реальный результат
Цель раннего опыта:
1. закрыть хотя бы одну привычку;
2. добавить и закрыть хотя бы одну задачу;
3. после первой победы получить отдельное Telegram-сообщение от ADAM;
4. кнопкой сразу открыть `/coach` и начать диалог с наставником;
5. сообщение дополнительно закрепляет продолжение Ударного дня и возвращение завтра.

Push отправляется только один раз и не должен ломать сам запрос отметки, если Telegram недоступен.

### 4. Завершение onboarding
После появления первой выполненной привычки и первой выполненной задачи старый флаг `app_tour_seen` закрывает onboarding, чтобы подсказки не возвращались в следующих сессиях.

## Проверка
- Python-файлы прошли `py_compile`.
- JS прошёл `node --check`.
- Миграция БД проверена на чистой SQLite-базе: новые поля создаются.
- Полный pytest в текущем контейнере не запустился из-за отсутствующих внешних зависимостей (`aiogram`, затем `openai`); это ограничение среды, а не ошибка синтаксиса проекта.
