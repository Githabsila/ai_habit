# ADAM — изменения по напоминаниям и интерфейсу

## Сделано
- Убран старый общий `send_reminders`, который рассылал одинаковое сообщение в 08:00/12:00/16:00/20:00.
- Напоминания по привычкам больше не отправляются по таймеру каждые 2 часа.
- Добавлена одна контрольная точка по привычкам в 12:00 локального времени пользователя.
- Контрольная точка отправляется только если есть хотя бы одна невыполненная привычка.
- За один локальный день контрольная точка может уйти максимум один раз.
- Текст 12:00 один, но каждый раз выбирается из разных живых формулировок; обращения только на «ты».
- В текстах убраны случайные медали/награды как эмодзи; для задач и мотивации используются отдельные смысловые наборы.
- Убрана формулировка «закрыть её с утра»: наставник учитывает, что привычка может быть запланирована позже.
- Исправлено склонение «1 задача / 2–4 задачи / 5+ задач».
- Исправлено отображение серии: «1 день / 2 дня / 5 дней».
- Статус серии изменён на «В ударе N дн.».
- В профиле надпись рамки изменена на «🔥 Твоя ударная серия!» без оранжевой обводки.
- В рейтинге медаль теперь находится сразу после имени в одной строке.
- Добавлено красивое полноэкранное окно «Поделиться достижением».
- Для обычных AI-сообщений добавлен локальный быстрый роутер: короткие запросы теперь сразу идут в быстрый вызов модели без отдельного LLM-классификатора.
- Для пользователей с активной серией убрано дублирование контрольного напоминания в 21:00 после риск-пинга в 20:00.

## Важно
- В текущей модели привычки нет отдельного времени выполнения. Поэтому наставник больше не утверждает, что конкретную привычку нужно сделать утром. Если нужно, следующим этапом можно добавить для каждой привычки `время/окно выполнения` и строить напоминания уже по нему.
- Загрузка пользовательских фото/кастомные рамки и отдельный Adam PRO с лимитами — оставлены следующим этапом, чтобы не смешивать их с исправлением напоминаний.


## AI-наставник — управление планом дня

- ADAM теперь реально изменяет `daily_plans` и `daily_plan_tasks`, а не только сообщает об изменении.
- Через AI-чат можно:
  - поставить/изменить/удалить главную задачу или цель дня;
  - отметить главную задачу выполненной/снять выполнение;
  - использовать «главная привычка дня» как синоним главной задачи;
  - добавить/изменить/удалить задачу плана дня;
  - отметить задачу плана выполненной по названию или номеру;
  - показать статус главной задачи вместе с планом дня.
- Добавлена AI-классификация команд для главной задачи и задач плана как резервный путь для свободных формулировок.
- Контекст AI уже получает фактический статус главной задачи из БД, поэтому ADAM видит, выполнена она или нет.
