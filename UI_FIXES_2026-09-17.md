# ADAM UI fixes — 2026-09-17

Implemented in the uploaded project:

1. Level ring uses one fixed SVG/viewBox geometry (cx=56, cy=56, r=49) at every viewport size; mobile rules now scale only the wrapper, preventing the dash-circumference mismatch that could leave an underdraw/shift. The ring is rotated so the progress starts at the top.
2. Mobile home streak card is compacted to remove excessive vertical stretching.
3. Today/quest CTA is constrained on narrow screens so its content stays visible inside the button.
4. ADAM chat removes decorative pseudo-element divider overlays that could appear as an extra line.
5. ADAM chat no longer adds 130px of unnecessary bottom padding; the composer remains in normal flow and the message area ends close to it.
6. Scroll-to-bottom control is centered above the composer, with centered hover/active transforms.
7. ADAM answer rendering is immediate: the frontend typewriter loop was removed. A short opacity fade gives response feedback without progressively changing message height.
8. Per-message infinite assistant bubble glow animation is disabled to reduce Telegram WebView rendering work.
9. Static asset query versions were bumped to avoid stale cached CSS/JS.

No backend/API behavior was changed; the visible response stretching was caused by frontend typewriter rendering after the API response arrived.
