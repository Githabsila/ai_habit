# Вернись в серию (долгий перерыв)

- **Когда:** 4–7 дней: 12:00 и 20:00; 8–30 дней: 18:00 через день; 31+: 18:00 раз в 3 дня
- **Кому:** Давно без отметок
- **Отключается:** Напоминания → «Серия»
- **Группа:** 3. Возврат и удержание
- **Отправляет:** `streak_scheduler.run_streak_reengagement_notifications`

Связано: [[Рассылки]], [[Серия]], [[streak_scheduler]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `reengage_long`).
