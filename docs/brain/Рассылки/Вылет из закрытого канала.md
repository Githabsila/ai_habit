# Вылет из закрытого канала

- **Когда:** Сразу при проверке (раз в 15 минут)
- **Кому:** Серия погасла или кончилась подписка (канал подключён)
- **Отключается:** Нельзя — это сообщение о доступе
- **Группа:** 2. Серия (ударный режим)
- **Отправляет:** `channel_sync.run_channel_sync`

Связано: [[Рассылки]], [[Серия]], [[channel_sync]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `channel_streak`).
