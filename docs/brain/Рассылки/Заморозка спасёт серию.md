# Заморозка спасёт серию

- **Когда:** 23:00, не чаще раза в неделю
- **Кому:** Серия под угрозой, заморозки нет, хватает монет
- **Отключается:** Напоминания → «Серия»
- **Группа:** 2. Серия (ударный режим)
- **Отправляет:** `streak_scheduler._maybe_send_freeze_upsell`
