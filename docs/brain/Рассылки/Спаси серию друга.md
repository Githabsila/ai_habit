# Спаси серию друга

- **Когда:** Раз в 5 минут, только днём по местному времени
- **Кому:** Серия друга недавно погасла
- **Отключается:** Напоминания
- **Группа:** 6. Друзья, рейтинг, приглашения
- **Отправляет:** `streak_scheduler.run_rescue_notifications`, `streak_scheduler._send_rescue_push`
