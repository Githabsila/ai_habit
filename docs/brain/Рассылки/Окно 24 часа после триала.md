# Окно 24 часа после триала

- **Когда:** 9–21, один раз
- **Кому:** Триал кончился, не оплатил
- **Отключается:** Админка → «Триал»
- **Группа:** 4. Пробный период
- **Отправляет:** `subscription_scheduler.run_trial_reminders`

Связано: [[Рассылки]], [[Триал]], [[subscription_scheduler]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `grace_notice`).
