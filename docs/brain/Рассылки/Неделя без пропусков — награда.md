# Неделя без пропусков — награда

- **Когда:** Воскресенье 10:00
- **Кому:** 7 дней подряд без пропусков, награду ещё не забирал
- **Отключается:** Напоминания → «Серия»
- **Группа:** 2. Серия (ударный режим)
- **Отправляет:** `streak_scheduler.run_weekly_streak_bonus`
