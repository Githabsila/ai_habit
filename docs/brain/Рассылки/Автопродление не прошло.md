# Автопродление не прошло

- **Когда:** Через 3 часа после конца срока
- **Кому:** Списания не было; доступ держится ещё сутки
- **Отключается:** Нельзя
- **Группа:** 5. Подписка и оплата
- **Отправляет:** `subscription_renewal.run_renewal_reminders`

Связано: [[Рассылки]], [[Подписка]], [[subscription_renewal]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `renew_failed`).
