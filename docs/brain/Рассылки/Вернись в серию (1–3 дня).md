# Вернись в серию (1–3 дня)

- **Когда:** 10:00 и 16:00 (у части людей ещё 21:00 — эксперимент)
- **Кому:** 1–3 полных дня без отметок; после первой отметки за день — тишина
- **Отключается:** Напоминания → «Серия»
- **Группа:** 3. Возврат и удержание
- **Отправляет:** `streak_scheduler.run_streak_reengagement_notifications`

Связано: [[Рассылки]], [[Серия]], [[streak_scheduler]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `reengage_10`).
