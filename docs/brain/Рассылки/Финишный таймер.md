# Финишный таймер

- **Когда:** 23:30, бот правит сообщение до полуночи
- **Кому:** То же: серия и пустой день
- **Отключается:** Напоминания → «Серия»
- **Группа:** 2. Серия (ударный режим)
- **Отправляет:** `streak_scheduler.run_streak_risk_notifications`, `streak_scheduler._run_countdown`

Связано: [[Рассылки]], [[Серия]], [[streak_scheduler]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `timer`).
