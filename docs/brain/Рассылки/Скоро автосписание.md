# Скоро автосписание

- **Когда:** 12:00 за 3 дня
- **Кому:** Включено автопродление
- **Отключается:** Нельзя
- **Группа:** 5. Подписка и оплата
- **Отправляет:** `subscription_renewal.run_renewal_reminders`

Связано: [[Рассылки]], [[Подписка]], [[subscription_renewal]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `renew_auto`).
