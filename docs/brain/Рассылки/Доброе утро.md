# Доброе утро

- **Когда:** 06:00
- **Кому:** Есть привычки; текст пишет ИИ (запасной — если модель недоступна)
- **Отключается:** Напоминания → «Утро»
- **Группа:** 1. День человека: привычки и план
- **Отправляет:** `morning_ping.run_morning_ping`

Связано: [[Рассылки]], [[Привычки]], [[morning_ping]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `morning`).
