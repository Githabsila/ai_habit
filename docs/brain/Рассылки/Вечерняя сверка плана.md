# Вечерняя сверка плана

- **Когда:** 19:00
- **Кому:** В плане дня есть незакрытое
- **Отключается:** Напоминания → «План»
- **Группа:** 1. День человека: привычки и план
- **Отправляет:** `coach.run_day_progress_check`

Связано: [[Рассылки]], [[Привычки]], [[coach]]

Образец можно прислать себе: админка → «Сообщения бота» / «Триал» (ключ `evening_plan`).
