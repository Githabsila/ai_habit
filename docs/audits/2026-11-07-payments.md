## Confirmed defects

**P1** — `handlers/payments.py:282`, категория «Деньги: выдача покупки».
1. `pre_checkout` для `subscription:` проверяет только владельца, `total_amount` нигде не сверяется.
2. `/api/subscription/invoice` отдаёт ссылку `createInvoiceLink` с payload `subscription:<uid>` без цены и срока.
3. После первой оплаты новые счета — по полной цене, но старая ссылка по вводной цене остаётся рабочей.
Сценарий: новичок сохраняет ссылку за 153 ⭐ и оплачивает её каждые 30 дней вместо 461 ⭐.
Исправление: в `pre_checkout` сверять `total_amount` с `invoice_spec(owner)["price"]`. Тест: старая ссылка — `ok=False`;
`test_review_the_checkout_takes_the_current_price` — текущая цена проходит.

**P2** — `pay_tribute.py:111`, категория «Деньги: вебхуки».
1. `_on_purchase` сверяет только сумму и валюту товара `sub_first` ($1.99).
2. Ссылка товара Tribute одна на всех, кому начислить — говорит подписанный вебхук.
3. `intro_price_open` не проверяется. Уже платившему $1.99 продлевает месяц.
Исправление: для `sub_first` без заказа под этот `purchase_id` и при `intro_price_open() == False` — не выдавать, сообщить админам
(вернуть деньги или выдать вручную). Тест-страж: `test_review_the_first_month_product_still_works_for_a_newcomer`.

**P3** — `subscription_flow.py:272`, категория «Подписка и сроки».
1. `refund_payment` вызывает `revoke_subscription` — `subscription_paid_until=NULL`.
2. Поток: `/refund <charge_id>` админа.
3. Оплаченные отдельными платежами месяцы не учитываются, автопродление Stars не выключается.
Исправление: если есть другие оплаченные платежи подписки — снять один период (`take_back_one_period`), иначе срок целиком; при
возврате платежа, на котором держится автопродление, — `set_auto_renew(False)`. Тесты: два платежа → остаётся месяц;
`test_review_refunding_an_autorenew_payment_turns_autorenew_off`; старый `test_refund_returns_stars_and_takes_the_subscription_back`
(единственный платёж снимается целиком) проходит.

**P4** — `handlers/payments.py:277`, категория «Деньги: выдача покупки». Для `avatar_frame:`, `answer_pack_stars:`,
`diamond_pack_stars:`, `booster:` id покупателя последним в payload не сверялся с плательщиком: звёзды списывались, `_credit_payment`
молча выходил. Исправление: та же проверка владельца, что у подписки.
