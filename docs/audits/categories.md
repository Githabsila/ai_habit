# Категории проверки (что проверяет каждый прогон)

Категории, не шаблоны: новый шаблон ошибки попадает в одну из них. «Механически» — есть тест-страж, который упадёт при регрессии.

| Категория | Чем закрыта в проекте | Механически? |
|---|---|---|
| Аутентификация Mini App | подпись initData (`webapp/telegram_auth.py`), `_authenticate`/`authenticate` на каждом `/api/*` (`CLAUDE.md`) | частично (тесты маршрутов) |
| Доступ (бан, анкета, возраст, подписка/триал) | `webapp/auth_helpers.py`, `middlewares/access_control.py`, `db/access_state.py` | частично |
| Права админа | `_authenticate_admin`, `ADMIN_IDS` | да (тесты 403) |
| Деньги: выдача покупки | идемпотентность `claim_fulfilment`, `claim_event`; при ошибке выдачи — 500 (`CLAUDE.md`) | частично |
| Деньги: вебхуки | проверка подписи, сверка суммы и валюты | частично |
| Подписка и сроки | `db/subscription.py`: 30 дней звёзды, календарные месяцы карта, запас 24 ч автопродления | да |
| Закрытый канал | выдача по оплате + серии, вылет ban+unban (`channel_sync.py`) | частично |
| Экранирование в сообщениях бота | HTML parse mode, `html.escape` пользовательских данных (`CLAUDE.md`) | частично |
| Календарный день | день человека по его поясу, план — смена в 03:00 | частично |
| Конкурентность | одноразовые действия (сундуки, награды, заказы) атомарно | частично |
| Секреты | только переменные окружения | нет |
| Фоновые рассылки | один раз на событие (ключи), тихие часы, лимиты | частично |
