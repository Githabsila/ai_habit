## Confirmed defects

**A1** — `db/subscription.py:345`, категория «Закрытый канал».
1. Ссылка создаётся только с `member_limit=1`, не сохраняется и не отзывается.
2. Ссылку получает человек после оплаты и серии; войти по ней может кто угодно.
3. `channel_sync` убирает id получателя; вошедший по пересланной ссылке друг не отслеживается, получатель может войти после конца
   подписки по старой ссылке.
Исправление: ссылка-заявка (`creates_join_request=True`, имя `user_<id>`), обработчик `handlers/channel_join.py` одобряет заявку только
получателю при действующем доступе; при вылете ссылка отзывается (`revoke_chat_invite_link`).
Тест: друг отклонён, получатель одобрен; `test_review_after_removal_the_old_link_is_revoked_and_refused`.

**A2** — `middlewares/access_control.py:50`, категория «Доступ». Бан проверялся только в `/start`; забаненный жал кнопки и говорил с
ИИ. Исправление: проверка `is_banned` в middleware после пропуска оплаты.

**A3** — `db/subscription.py:338`, категория «Конкурентность». Проверка `channel_granted` и отметка разделены `await
create_chat_invite_link`. Исправление: атомарный `UPDATE ... WHERE channel_access_granted_at IS NULL` до запроса, откат при ошибке.

**A4** — `db/inactive_purge.py:55`, категория «Календарный день». Удаление не ждало `WARN_DAYS` после предупреждения. Исправление:
условие `warned_at <= now - WARN_DAYS`.

**A5** — `middlewares/access_control.py:60`. Пропуск `successful_payment` перенесён выше проверок 16+ и бана.
