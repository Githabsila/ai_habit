# Подключение оплаты картой (Tribute) и закрытого канала для ADAM

Инструкция для владельца аккаунта Tribute и канала. Займёт около часа, плюс время на проверку личности в Tribute.
Ничего не нужно программировать: всё делается в Telegram, в конце нужно передать два значения — ключ и ID канала.

**Важно про безопасность:** ключ API Tribute — как пароль от кассы. Не публикуйте его в чатах, группах и на скриншотах.
Передайте его только Алексу лично (раздел «Что передать в конце»).

---

## Часть 1. Tribute: аккаунт автора

1. Откройте в Telegram **@tribute** → нажмите **«Открыть»** (мини-приложение).
2. Выберите роль **автора** (вы продаёте, а не покупаете).
3. Пройдите все **«Задания»** (синяя плитка вверху): заполните «Расскажите о себе» и пройдите **проверку личности**.
   Без проверки продавать нельзя. Подтверждение может занять от нескольких часов до пары дней.
4. **«Выплаты»** → укажите, куда выводить деньги (карта или другой предложенный способ).

**Проверка:** в заданиях не осталось обязательных пунктов, в «Выплатах» указан способ вывода.

---

## Часть 2. Tribute: 8 продуктов

Где создавать: главный экран Tribute → **«Инфопродукты и контент»**.
Не «Товары» (они для физических вещей с доставкой) и не «Подписки» (это платный канал — см. часть 4, его к Tribute **не подключаем**).

Для каждой строки таблицы:

1. «Инфопродукты и контент» → **создать**.
2. **Название** — из таблицы.
3. **Цена** — **ровно** как в таблице, **валюта USD (доллары)**. Если цена или валюта не совпадут, система ADAM не примет продукт.
4. **Описание / содержимое** (если просят): «Доступ откроется в приложении ADAM сразу после оплаты. Открыть: @aihabbit_bot».
   Файл прикладывать не нужно — покупку выдаёт сам бот ADAM.
5. **Опубликуйте** продукт (он должен быть активным, не черновиком).

| № | Название | Цена (USD) |
|---|---|---|
| 1 | ADAM Pro — первый месяц | 1.99 |
| 2 | ADAM Pro — 30 дней | 5.99 |
| 3 | +50 ответов ADAM | 1.99 |
| 4 | +100 ответов ADAM | 3.99 |
| 5 | Бустер x2 Adam Coin на 24 часа | 1.29 |
| 6 | 10 алмазов | 1.99 |
| 7 | 50 алмазов | 7.99 |
| 8 | Рамка Double Gold | 3.99 |

**Проверка:** в «Инфопродукты и контент» видно 8 активных продуктов с этими ценами в долларах.

## Часть 3. Tribute: ключ API и вебхук

1. Главный экран Tribute → **«Ещё»** (вверху справа) → **настройки** → раздел про **API** (может называться «API Keys», «API», «Для разработчиков»).
2. **Создайте ключ API.** Скопируйте его — он понадобится один раз (см. «Что передать в конце»).
3. Там же найдите **вебхуки** («Webhooks», «Уведомления») и вставьте адрес:
   ```
   https://aihabit-production.up.railway.app/api/pay/webhook/tribute
   ```
   Сохраните.

Если разделов API или вебхуков не видно — сделайте скриншот экрана «Ещё» и отправьте Алексу, или напишите в поддержку Tribute:
«Хочу подключить API и вебхуки для продажи цифровых продуктов через своего бота».

---

## Часть 4. Закрытый Telegram-канал

Этот канал будет открываться людям, которые оплатили ADAM и держат серию 3 дня подряд. Пускать и убирать людей будет сам бот ADAM.
**Не подключайте этот канал к платным подпискам Tribute** — иначе будет два «вахтёра», и люди будут вылетать или попадать без оплаты.

1. Telegram → **новый канал** (карандаш → «Создать канал»).
2. Название и описание — любые (можно поменять позже), аватарка по желанию.
3. Тип канала — **«Частный»** (не публичный, без @ссылки).
4. Создайте канал, пропустите добавление подписчиков.
5. Канал → название вверху → **«Администраторы»** → **«Добавить администратора»** → найдите **@aihabbit_bot** → включите права:
   - **«Добавление подписчиков»** / «Пригласительные ссылки»,
   - **«Блокировка пользователей»** / «Удаление участников».
   Остальные права можно выключить. Сохраните.
6. **ID канала:** опубликуйте в канале любой пост → перешлите его боту **@userinfobot** → он ответит строкой вида `Id: -1001234567890`. Это и есть ID (с минусом в начале).
   Если @userinfobot не отвечает — подойдёт **@getidsbot** (так же: переслать пост).

**Проверка:** в «Администраторах» канала есть @aihabbit_bot с правами на приглашения и удаление; ID начинается с `-100`.

Наполнять канал можно спокойно — бот начнёт пускать людей только после того, как Алекс включит это у себя.

---

## Что передать в конце (Алексу лично)

1. **Ключ API Tribute** — лично, в личные сообщения. После того как Алекс подтвердит «вставил», **удалите это сообщение** у себя и у него.
2. **ID канала** (`-100…`) — это не секрет, можно просто написать.
3. Скриншот списка из 8 продуктов (для сверки цен).

Дальше всё делает команда ADAM: подключает продукты к приложению, проверяет оплату, включает канал.

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Tribute не даёт создать продукт | Сначала закончите все «Задания» и проверку личности |
| Нельзя выбрать доллары | Скриншот экрана создания продукта — Алексу |
| Не нахожу API / вебхуки | Скриншот «Ещё» — Алексу, или вопрос в поддержку Tribute |
| @aihabbit_bot не находится при добавлении админа | Сначала откройте @aihabbit_bot и нажмите «Старт», потом добавьте снова |
| Случайно подключили канал к подпискам Tribute | Отключите канал от подписок Tribute, бот ADAM управляет им сам |
